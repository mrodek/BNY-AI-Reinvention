# Project Overview

## Purpose

Create a trustworthy, evidence-informed book from the existing outline. The book should later serve as structured input for a knowledge graph and a companion app that helps the organization learn over time.

## Roles

### Author / Editor

- Owns truth, strategy, lived experience, and publishability
- Reviews drafts, notes gaps, and approves revisions

### Ghostwriter / Research Partner

- Expands the outline into a manuscript plan
- Researches supporting literature
- Drafts and revises chapters
- Tracks sources, claims, and graph-ready outputs

## Output Principles

- Keep durable artifacts on disk.
- Distinguish evidence-backed guidance from opinion and emerging practice.
- Make each chapter independently operable.
- Write the book so it can later be decomposed into graph-ready knowledge objects.

## Immediate Goals

1. Convert the outline into a working chapter map.
2. Stand up a repeatable chapter workflow.
3. Draft the book chapter by chapter.
4. Extract structured knowledge from approved chapters.
5. Use the structured knowledge to guide app design.

## Restart Rule

If work resumes after a pause, start with:

1. `00_admin/progress_tracker.md`
2. `02_outline/chapter_map.md`
3. The current chapter folder in `04_manuscript`
