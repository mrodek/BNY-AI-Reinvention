# Manuscript Directory

Create one folder per chapter here. Suggested structure:

```text
chapter_01/
  chapter_brief.md
  research_tracker.md
  claim_register.md
  source_notes.md
  draft_v1.md
  draft_v2.md
  final.md
  graph_extract.md
```

Do not start a chapter draft without first creating its brief and research tracker.

When a chapter begins using source-backed claims in prose, create `source_notes.md` so the draft stays readable while citations remain traceable.

Editorial review can happen directly in chat. If no separate notes file is used, capture material editorial comments in `00_admin/progress_log.md`.
