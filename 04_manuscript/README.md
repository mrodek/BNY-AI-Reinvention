# Manuscript Directory

Create one folder per chapter here. Suggested structure:

```text
chapter_01/
  chapter_brief.md
  research_tracker.md
  claim_register.md
  draft_v1.md
  editor_notes.md
  draft_v2.md
  final.md
  graph_extract.md
```

Do not start a chapter draft without first creating its brief and research tracker.
